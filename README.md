# Retail Sales Analysis — Power BI

## Objective
Connect Power BI to a retail company's flat files (Excel/CSV) and MySQL database, import and combine the data, and build visuals to analyze sales by product, store, customer, and time.

## Data Sources
- Flat files: Excel/CSV (e.g., product, customer, store data)
- MySQL database: transactional sales data

## Steps
1. Connected Power BI Desktop to Excel/CSV files via Get Data > Excel/Text-CSV.
2. Connected to MySQL database via Get Data > MySQL Database.
3. Loaded and combined tables in Power Query Editor.
4. Built relationships between tables in Model view.
5. Explored Power BI interface: Fields pane, Visualizations pane, Report/Data/Model views.
6. Created visuals:
   - Sales by Product (bar chart)
   - Sales by Store (map/column chart)
   - Sales by Customer (table/treemap)
   - Sales over Time (line chart)
7. Added slicers for interactive filtering (date, store, category).

## Tools Used
Power BI Desktop, MySQL, Excel/CSV

## Output
Interactive dashboard analyzing retail sales trends across product, store, customer, and time dimensions.
